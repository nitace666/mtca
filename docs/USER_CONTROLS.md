# MTCA 用户控制接口

> `/重要 /循环 /归档 /雾化` — 直接打到对话里,或通过 CLI / GUI 调用。
> **任何命令直达 L0 层**,跳过任何压缩。

## 命令一览

| 命令 | 干什么 | 可逆? |
|------|--------|--------|
| `/重要` | 段落锁底,永远 L1,优先召回 | ✅ 可降级 |
| `/循环 X` | 打周期标签(`周一`/`月初`/`每天`...),跳过时间衰减 | ✅ 可取消 |
| `/归档` | tier 降为隐藏,不主动召回(L0 全文保留) | ✅ 可恢复 |
| `/雾化 <锚点句>` | **物理擦除 L0-细节**,保留骨架 + 锚点句(≤20 字) | ❌ **不可逆** |

每个命令:
- 在对话任意位置打 `/xxx` 即识别(自然语言前缀)
- 可通过 CLI 调用:`python -m src.cli.user_controls <cmd> <seg_id> [...]`
- GUI 段落详情页有对应按钮

## 命令详解

### /重要

**用途**:把"这条很重要"标出来,AI 永远优先召回。

**CLI**:
```bash
python -m src.cli.user_controls important <seg_id>
```

**GUI**:段落详情 → 点 "⭐ 标记为重要" 按钮。

### /循环 X

**用途**:周期性话题(每周一例会 / 月初 OKR),跳过时间衰减,持续出现在时间线。

**X 支持**:周一 / 周二 / ... / 周日 / 月初 / 月末 / 每天 / 每小时

**CLI**:
```bash
python -m src.cli.user_controls cycle <seg_id> "每周一"
```

### /归档

**用途**:暂时不想看,但 L0 全文保留。需要时搜关键词还能找到。

**CLI**:
```bash
python -m src.cli.user_controls archive <seg_id>
```

### /雾化 <锚点句>

**用途**:**永久擦除**详细对话内容,只保留骨架(标题 + 时间 + 关键词 + 锚点句 ≤ 20 字)。

⚠️ **不可逆**。物理删除,无法恢复。

**为什么需要**:心理健康权 —— "我不要这段具体内容了,但话题存在这件事我承认"。

**CLI**:
```bash
python -m src.cli.user_controls fog <seg_id> --anchor "≤20字锚点"
```

**GUI**:段落详情 → 点 "雾化" → 弹强警告对话框 → 输入锚点句 → 确认。

## 紧急追踪(`/紧急 /完成 /延期`)

| 命令 | 行为 |
|------|------|
| `/紧急 <seg_id> <时间>` | 标记段为紧急追踪,过期前主动提醒 |
| `/完成 <seg_id>` | 紧急事项已完成,移出追踪 |
| `/延期 <seg_id> [时间]` | 顺延截止时间(默认 7 天) |

### 时间格式

| 写法 | 含义 |
|------|------|
| `明天` / `后天` | 1 / 2 天后 |
| `下周` / `下月` | 7 / 30 天后 |
| `3d` / `7d` / `30d` | N 天后 |
| `尽快` / `马上` | 今天 |
| `2026-07-10` | ISO 日期 |
| `2026-07-10T15:30` | ISO 日期 + 时间 |

**CLI**:
```bash
python -m src.cli.user_controls urgent <seg_id> "明天" --anchor "演示前 PPT 必改完"
python -m src.cli.user_controls done <seg_id>
python -m src.cli.user_controls postpone <seg_id> "7d"
```

## 4 象限分类(高层)

MTCA 把段落按"重要度 + 紧急度"自动分类到 4 个象限 + 1 个特殊类(URGENT)。具体分类由系统根据内容自动判断,你不需要手动调。

| 类别 | 含义 | 例子 |
|------|------|------|
| **Q1 重要 + 紧急** | 必做,锁底,永不丢失 | "明天客户演示" |
| **Q2 重要 + 不紧急** | 长期价值 | "3 年前的学习笔记" |
| **Q3 不重要 + 紧急** | 琐事,快过期 | "超市买牛奶" |
| **Q4 都不沾** | 闲聊,几天就沉 | "今天天气不错" |
| **URGENT 已强调** | 你说过"X 时要这个" | "周一前完成" |

**关键规矩**:Q1 + 标了 `/重要` 的 + URGENT = 3 类永不遗忘。

GUI "4 象限"标签页直观展示。过期 URGENT 段会在顶部红条显示。
